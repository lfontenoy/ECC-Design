# UI kit · Sitio del canal

Superficie web de Entrena con Ciencia: casa de los videos, de las fichas de estudio y de las dos guías
(PESO y PROTE) que se piden por comentario en los Reels.

| Archivo | Superficie |
|---|---|
| `SiteHeader.jsx` | Barra fija navy con blur, nav subrayado en cyan y CTA amarillo. |
| `HomeHero.jsx` | Hero con atmósfera navy, entrada escalonada y tarjeta del estudio de la semana. |
| `VideoGrid.jsx` | Parrilla 4:5 de covers con filtro por tema y PMID visible. |
| `LeadMagnet.jsx` | Captura de correo para las guías PESO / PROTE, con estado enviado. |
| `StudyArticle.jsx` | Ficha de estudio: mito, metodología, resultado, matices, referencias. |
| `SiteFooter.jsx` | Pie negro-navy con aviso de que el contenido no sustituye consulta médica. |

Interacciones del `index.html`: navegar entre Videos / Fichas / Guías, filtrar por tema,
elegir guía PESO o PROTE y enviar el formulario.

Nota: no habia fotografia de marca disponible. Los thumbnails de video son lienzos navy con la
tipografía del cover; sustituirlos por los fotogramas reales cuando existan.
